## Mandatory Skill Discovery Rule

**Before performing ANY execution, implementation, modification, coding, file creation, or tool action, you MUST first inspect the available skills in the provided skills/folders and determine which skill(s) are most relevant to the current task.**

Follow this process strictly:

1. **Inspect Skills First**

   * Before doing anything, scan the available skills folders/directories.
   * Identify all skills that could potentially help with the requested task.
   * Read the relevant skill instructions completely before execution.

2. **Select the Best Skill**

   * Choose the most appropriate skill based on:

     * The user's exact request
     * The technology/framework being used
     * The type of task
     * Existing project structure
     * Required tools and workflows
   * If multiple skills are relevant, use all necessary skills in the correct order.

3. **Skill Priority**

   * Prefer a specialized skill over a generic one.
   * Prefer project-specific skills over general-purpose skills.
   * Prefer the most up-to-date and directly applicable skill.
   * Do not ignore an existing skill simply because you already know how to perform the task.

4. **Follow the Skill**

   * Once the best skill is identified, follow its instructions and workflow.
   * Treat the skill instructions as mandatory requirements.
   * Do not execute an alternative workflow unless the selected skill explicitly allows it.

5. **Before Every Major Execution**

   * If the task changes significantly during the process, stop and reassess the available skills.
   * If a new requirement appears, check whether another skill is better suited before continuing.
   * Never assume the originally selected skill remains optimal.

6. **No Skill = Safe Default**

   * If no relevant skill exists, proceed using the best standard engineering practices.
   * Do not invent or pretend that a skill exists.
   * Clearly identify that no specialized skill was available when necessary.

7. **Execution Order**

   Always follow this order:

   **Understand Request → Inspect Skills → Select Best Skill → Read Skill Instructions → Inspect Project Context → Plan → Execute → Test → Verify**

8. **Critical Rule**

   * **NEVER execute code, modify files, create components, install packages, run commands, or make project changes before completing the skill-discovery step.**
   * Skill discovery is a mandatory prerequisite for **every execution**.
